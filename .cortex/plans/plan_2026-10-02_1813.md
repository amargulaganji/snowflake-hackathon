## Context

Explored all frontend components, backend routers/services, types, and CSS. Key findings:
- `getMemberDetail()` API client exists but is **never called** from the frontend
- `MemberDetail` type with encounters/medications/diagnoses/labs is **defined but unused**
- `useAgent` and `useMemberSearch` both track `error` state but **never surface it in UI**
- Agent `/ask` endpoint sends a single message — no conversation history
- Backend `run_agent()` accepts any `messages[]` list, so multi-turn is trivial to add
- All styling uses plain CSS with CSS variables (no CSS modules/Tailwind)

## Implementation Steps

### Feature 1: Member 360 Detail Panel (tabbed clinical data)
1. **New component** `frontend/src/components/MemberDetail.tsx` — Tabbed panel (Encounters | Medications | Diagnoses | Labs) with sortable tables. Calls `getMemberDetail()` when a member is selected.
2. **New hook** `frontend/src/hooks/useMemberDetail.ts` — Fetches and caches member detail data.
3. **Edit** `App.tsx` — Add MemberDetail below MemberProfile in sidebar (or as a collapsible panel in the main area above chat).
4. **CSS** — Add tab styles, table styles to `globals.css`.

### Feature 2: Suggested Quick-Ask Questions
1. **New component** `frontend/src/components/QuickActions.tsx` — Renders 4-5 contextual buttons based on the selected member's risk_flags and profile (e.g., "Polypharmacy risk?", "Drug interactions?", "Abnormal labs?", "Policy compliance for [drug]?").
2. **Edit** `ChatPanel.tsx` — Show QuickActions in the empty state when a member is selected but no messages exist yet. Clicking a button triggers `onSend()`.
3. **CSS** — Quick-action pill/chip styles.

### Feature 3: Chat History / Multi-turn Conversations
1. **Edit** `backend/app/routers/agent.py` — Accept optional `messages` array in `AskRequest`. Build the full conversation thread (all previous user+assistant messages) and send to the agent.
2. **Edit** `backend/app/models/schemas.py` — Add `messages: list[dict] | None = None` to `AskRequest`.
3. **Edit** `frontend/src/api/client.ts` — Pass the full message history in the `/ask` POST body.
4. **Edit** `frontend/src/hooks/useAgent.ts` — Accept messages array parameter.
5. **Edit** `App.tsx` — Pass `messages` to the `ask()` call.

### Feature 4: Export / Print Clinical Summary
1. **New component** `frontend/src/components/ExportButton.tsx` — Button in the chat header. On click, generates a print-friendly HTML view of the conversation (member header, Q&A pairs with evidence, timestamps) and triggers `window.print()` with a print stylesheet.
2. **Edit** `ChatPanel.tsx` — Add ExportButton to the chat header area.
3. **CSS** — Add `@media print` stylesheet for clean A4-formatted output.

### Feature 5: Medication Timeline Visualization
1. **New backend endpoint** `GET /members/{member_id}/medications/timeline` in `members.py` — Queries the agent for medication start/end dates and interaction flags, returns structured JSON.
2. **New component** `frontend/src/components/MedicationTimeline.tsx` — Horizontal timeline rendered with pure CSS/HTML (no chart library needed). Shows medication bars on a time axis, overlapping meds visible, interaction flags highlighted in red.
3. **New hook** `frontend/src/hooks/useMedicationTimeline.ts` — Fetches timeline data.
4. **Edit** `MemberDetail.tsx` — Add "Timeline" as a 5th tab.
5. **CSS** — Timeline bar styles, interaction highlight styles.

### Feature 6: Error Handling & Loading States
1. **New component** `frontend/src/components/ErrorBanner.tsx` — Dismissable error banner with retry button.
2. **Edit** `MemberSearch.tsx` — Surface `error` from `useMemberSearch`, show ErrorBanner.
3. **Edit** `App.tsx` — Surface `error` from `useAgent`, show inline error in chat with retry.
4. **Edit** `ChatPanel.tsx` — Show error state as a red chat bubble with "Retry" button.
5. **CSS** — Error banner/toast styles.
